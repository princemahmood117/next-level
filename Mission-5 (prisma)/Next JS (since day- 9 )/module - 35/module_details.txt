 visual data flow of search-params : 

Current URL: ?page=2
     ↓
searchParams (read-only) = { page: "2" }
     ↓
searchParams.toString() = "page=2"
     ↓
new URLSearchParams("page=2") = params (modifiable)
     ↓
params.set("page", "3")
     ↓
params = { page: "3" }
     ↓
params.toString() = "page=3"
     ↓
router.push("?page=3")
     ↓
New URL: ?page=3
